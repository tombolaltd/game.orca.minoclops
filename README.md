### Creating a new Game
- Create a new Repo on GitHub setting project as the Template.
- Name it game.arcade.GAME_NAME.
- Pull that repo and run `npm run setup` as described below to finish setup.
- Then free to start work on the game project.

## Getting Started

This is an example of how you may give instructions on setting up your project locally.
To get a local copy up and running follow these simple example steps.

### Setup

```sh
npm run setup
```

When prompted enter the following info when requested:
- Game Name: name of the game, e.g. spin-1, scratch, cascade.
- Skin Name: name of the skin, e.g. cosmos, galleon or phoenix.
- Category: (Optional) the category the game fits in e.g. spin, scratch
